# Pafta

Colour themes for VS Code from the Pafta desktop rice: a printed topographic map sheet by day
(**Pafta Paper**), a dark nautical chart under a bridge light at night (**Pafta Night**).

Every colour is a printing plate of a topo map: black for type and frame, brown for relief,
blue for water, green for vegetation, red for roads, and a rare magenta overprint for the
"you are here" mark (cursor, active tab, badges).

| Syntax                         | Colour  |
| ------------------------------ | ------- |
| keywords                       | brown   |
| strings                        | green   |
| functions, methods             | blue    |
| numbers, constants, booleans   | red     |
| types, classes                 | ochre   |
| tags, attributes, properties   | cyan    |
| regex, escapes                 | magenta |
| comments                       | grey (ink3), italic |

Pick one with `Preferences: Color Theme`. The palette lives in the
[pafta repo](https://github.com/melihgurlek/pafta) (`palette.toml`).
